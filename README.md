# Portfolio Summary – Daniel França

This document summarizes key academic software projects I developed during my studies at FATEC Araras. The full version of the portfolio (in Portuguese) is available on my GitHub repository, as it was originally submitted to the university in that language as part of my graduation requirements.

## 📁 Full academic portfolio: https://github.com/danielfransa/FATEC-Portifolio

### 📘 Project: Share Way Education (SWE)
An academic social network to promote knowledge exchange through the sharing and rating of educational content such as books, articles, videos, and courses.
Stack: PHP (backend), MySQL, HTML/CSS/Bootstrap (frontend), Git/GitHub.
Role: Fullstack developer. Responsible for user interface and relational database modeling.
GitHub: https://github.com/danielfransa/PI-Fatec-II-Semestre

### 🍎 Project: Food Connect
A donation platform connecting food donors (supermarkets, restaurants, producers) to social institutions such as food banks and shelters.
Stack: Django (Python), MongoDB, HTML/CSS/JavaScript, Figma.
Role: Frontend developer. Responsible for HTML/CSS screens and user interactions.
GitHub: https://github.com/danielfransa/PI_3Semestre_2023

### 📱 Project: ABA Monitoring App
A multiplatform system developed for the Instituto Inclusivamente to assist in tracking autism therapy protocols (ABA – Applied Behavior Analysis).
Stack: Angular (Web), Flutter (Mobile), Ruby on Rails (initial API), Java Spring (final API), PostgreSQL.
Role: Backend developer (Rails → Spring), Mobile developer (Flutter), Deployment management (Render, Vercel).
GitHub:
- Web (Angular): https://github.com/danielfransa/FATEC_aba_project_web
- Mobile (Flutter): https://github.com/danielfransa/AppAbaFlutter
- Backend (Java): https://github.com/danielfransa/FATEC_aba_project_backend
- Initial API (Rails): https://github.com/danielfransa/aba_api_rails
